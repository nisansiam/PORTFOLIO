HOW TO PUT THIS ON GITHUB PAGES
1. Create a repository on github.com (e.g. "portfolio").
2. Add file > Upload files. Drag in ALL the files from this folder (index.html, work.html, about.html, contact.html, admin.html, style.css, site.js, content.js). Commit.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. Your site appears at https://YOUR-USERNAME.github.io/portfolio/ in a minute or two.

HOW TO EDIT LATER
Open https://YOUR-USERNAME.github.io/portfolio/admin.html, edit, click "Download content.js",
then upload that file to the repository (it replaces the old one) and commit.
